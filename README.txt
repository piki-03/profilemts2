Website MTsN 2 Sukoharjo (HTML, CSS, JS statis)
Buka index.html di browser. Tidak perlu server atau instalasi.

Mengganti gambar:
- Logo resmi : timpa assets/img/logo-mtsn2skh.svg (atau ganti nama file di index.html jika memakai .png).
- Foto kegiatan : assets/img/kegiatan/ (mabit, tahfidz, studytour, adiwiyata)
- Foto lomba : assets/img/lomba/ (robotik, futsal, sains)
File saat ini adalah gambar pengganti bergaya ukiyo-e. Setelah mengganti dengan foto asli (.jpg/.webp),
ubah ekstensi di index.html dan js/main.js (cari ".svg").
Data yang perlu diverifikasi madrasah: nomor telepon, email, tingkat lomba futsal 2024, jumlah siswa/guru.
